# Blazor web app

Student used and configured Blazor to open the project.

Added a few functionalities:
- lenghten the weather forecast from 5 to 10 days,
- added warm days counter (above 15 degrees Celsius):
  user can click the button to filter out the warm days and sum them up (sum is shown below the forecast),
  filtering is executed using LINQ. user can restore the forecast to the state before filtering.
- added filtering by name (case sensitive):
  user inputs text in dedicated field and the table is filtered using LINQ and Contains method
